\section{Project Overview \& Objective}
% ═══════════════════════════════════════════════════════════════════════════════

\highlight{HireSense} is a next-generation applicant tracking and talent intelligence system designed to automate the recruitment lifecycle. Unlike traditional systems that rely on basic keyword matching, HireSense utilises \highlight{Generative AI (NVIDIA NIM)} and \highlight{Vector Embeddings} to understand the deeper semantic intent behind resumes and job descriptions.

The system provides a full-stack, cloud-native platform that gives recruiters:
\begin{itemize}[noitemsep]
    \item Automated ATS compliance scanning powered by a 70-billion parameter LLM.
    \item Multi-factor semantic match scoring using cosine similarity on 384-dimensional vectors.
    \item A drag-and-drop recruitment pipeline with real-time status tracking.
    \item An AI Finder for semantic search across all ingested candidate profiles.
    \item Resume rewriting assistance using generative AI.
\end{itemize}

\section{Core Architecture \& Workflow}
% ═══════════════════════════════════════════════════════════════════════════════

\subsubsection*{Step A: Data Ingestion (PDF Parsing)}
\begin{itemize}[noitemsep]
    \item \textbf{Library:} \code{PyMuPDF (fitz)}
    \item \textbf{Action:} Extracts raw text from binary PDF files with high fidelity, maintaining structural context.
\end{itemize}

\subsubsection*{Step B: Semantic Vectorisation}
\begin{itemize}[noitemsep]
    \item \textbf{Model:} HuggingFace \code{all-MiniLM-L6-v2}
    \item \textbf{Action:} Converts the resume and Job Description (JD) into \textbf{dense vectors}.
    \item \textbf{Logic:} Enables matching ``Software Engineer'' with ``Programmer'' via \textbf{Cosine Similarity}.
\end{itemize}

\subsubsection*{Step C: Generative Intelligence (NVIDIA NIM)}
\begin{itemize}[noitemsep]
    \item \textbf{Model:} \code{meta/llama-3.1-70b-instruct}
    \item \textbf{Action:} Performs a deep ``compliance scan'' identifying structural flaws (missing contact info, weak action verbs, formatting issues).
\end{itemize}

\subsubsection*{Step D: Data Persistence Pipeline}
\begin{itemize}[noitemsep]
    \item All analysis results are stored in \textbf{Supabase PostgreSQL} tables.
    \item \textbf{Deduplication:} Automatically identifies previously processed Job Descriptions to conserve API tokens.
\end{itemize}

\section{Precision Scoring Matrix (The Algorithm)}
% ═══════════════════════════════════════════════════════════════════════════════

HireSense calculates the \textbf{``Match Score''} using a weighted multi-factor precision matrix:

\begingroup
\setlength{\tabcolsep}{8pt}
\renewcommand{\arraystretch}{1.4}
\begin{tabularx}{\linewidth}{@{}L{3.5cm} C{2cm} X@{}}
    \toprule
    \textbf{Factor} & \textbf{Weight} & \textbf{Algorithm / Method} \\
    \midrule
    \rowcolor{lightgray}
    Semantic Similarity & \textbf{40\%} & Cosine Similarity between Resume and JD embeddings. \\
    Keyword Coverage    & \textbf{30\%} & LLM-based Named Entity Recognition (NER) for core skills. \\
    \rowcolor{lightgray}
    Experience Fit      & \textbf{20\%} & Regex-based heuristic extracting and comparing years of exp. \\
    Resume Strength     & \textbf{10\%} & Formatting score based on length and metric density. \\
    \bottomrule
\end{tabularx}
\endgroup

\vspace{6pt}
The final score is computed as:
\[
    \text{FinalScore} = 0.40\,S_{\text{semantic}} + 0.30\,S_{\text{skill}} + 0.20\,S_{\text{experience}} + 0.10\,S_{\text{strength}}
\]

\section{Key Presentation Highlights for the Professor}
% ═══════════════════════════════════════════════════════════════════════════════

\begin{enumerate}[noitemsep, leftmargin=*, label=\textbf{\arabic*.}]

    \item \highlight{``Fail-Safe'' Mocking Engine} --- If external APIs (NVIDIA NIM) hit rate limits, the system automatically switches to a \textbf{Mocking Engine}, providing realistic heuristic data instead of crashing.

    \item \highlight{Semantic Search vs.\ Keyword Search} --- HireSense understands \emph{concepts}, not just words. A resume mentioning ``PyTorch'' will match a JD mentioning ``deep learning frameworks'' because the embeddings encode semantic meaning.

    \item \highlight{Data Compliance (GDPR)} --- The \textbf{Delete} functionality purges sensitive candidate data on request, demonstrating awareness of data compliance requirements.

    \item \highlight{Editorial Design} --- The \textbf{Dark Mode Glassmorphism} UI provides an ``authoritative / AI-first'' aesthetic with SVG icons, animated theme toggle, and real-time pulse animations during background processing.

\end{enumerate}

\section{Conclusion \& Future Scope}
% ═══════════════════════════════════════════════════════════════════════════════

The \textbf{HireSense} platform successfully demonstrates the integration of state-of-the-art Generative AI (\textbf{Llama 3.1 via NVIDIA NIM}) and Vector Databases (\textbf{Supabase pgvector}) to solve the complex real-world problem of talent acquisition at scale. The system provides a robust, low-latency solution that goes beyond keyword matching to true semantic evaluation.

\subsubsection*{Future Scope}
\begin{itemize}[noitemsep]
    \item \textbf{Explainable AI (XAI):} Providing candidates with deeper, specific feedback on how to improve their match score for a particular role.
    \item \textbf{Direct Interview Automation:} Integrating with calendar APIs to automatically schedule interviews for top-ranked candidates.
    \item \textbf{Multi-modal Analysis:} Expanding the system to analyze video introductions and portfolio projects using vision-capable LLMs.
\end{itemize}
